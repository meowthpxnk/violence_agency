# Application README

## Rule

A project README starts with the name and what the application does. Then it includes a table of contents, the module tree and which files host which clients, how to run it in development and in production, the database entities when a database exists, and environment variables in an HTML table. Mark each variable as required, optional, or optional with a printed default.

## Why

An agent that adds a setting or a module has one place to update.

## Exceptions

A library package with no process and no database skips the run and database sections.
