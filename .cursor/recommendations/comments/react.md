# React comments

## Rule

Use the same marker policy in a component file. Mark large blocks with `// -->` and smaller blocks with `// ->`. Explain a hook or a branch when its name does not state the action.

## Why

Frontend and backend files should scan the same way.

## Exceptions

Do not comment JSX that only renders a labeled prop.
