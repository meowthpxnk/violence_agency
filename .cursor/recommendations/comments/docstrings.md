# Docstrings

## Rule

Put a docstring on every Python class. Put one on a function when the name does not state the action. Comment a line inside a function when the statement is not obvious.

## Why

The name carries the obvious cases. The docstring carries the rest.

## Exceptions

A method whose name already states the action does not need a docstring.
